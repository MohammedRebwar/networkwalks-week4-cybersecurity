# Networkwalks Cybersecurity Internship — Week 4

## Overview

This repository contains my Week 4 cybersecurity internship work completed as part of the Networkwalks Cybersecurity & Ethical Hacking program.

The week focused on practical penetration-testing activities, web application assessment, information discovery, authentication testing, database exposure analysis, and security findings.

All testing was performed as part of the authorized internship/lab environment.

## Modules

### M1 — Web Application Reconnaissance & Testing

- WHOIS and DNS enumeration
- Web technology identification
- HTTP header analysis
- Website and directory discovery
- obots.txt analysis
- Authentication page assessment
- SQL injection testing
- Portal access verification

### M2 — Password & PDF Security Testing

- PDF security analysis
- Hash extraction
- Password-cracking testing
- Password recovery
- PDF decryption

### M3 — Information & Database Exposure

- Directory enumeration
- Staff portal discovery
- Sitemap analysis
- Database backup discovery
- Database structure analysis
- Staff data exposure assessment
- Shareholder data exposure assessment

### M4 — Final Penetration Test Report

The final penetration-testing report summarizes the Week 4 assessment, findings, observations, and security recommendations.
